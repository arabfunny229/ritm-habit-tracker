Синхронизация между устройствами

Подключите приватный GitHub-репозиторий: отметки будут доступны на телефоне и компьютере.

Создайте fine-grained token с доступом только к вашему репозиторию и разрешением Contents: read and write.
Сначала создайте в GitHub отдельный репозиторий с видимостью «Приватный».
При первом подключении текущие данные будут записаны в файл приватного репозитория. Если файл уже есть, приложение предложит загрузить его.

Токен не добавляется в файлы приложения. Он сохраняется только в выбранном хранилище браузера и отправляется напрямую в GitHub API. Создать приватный репозиторий ↗ · Создать fine-grained token ↗
