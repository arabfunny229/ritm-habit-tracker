# Ритм — личный трекер привычек

Русскоязычное адаптивное приложение, подготовленное для GitHub Pages. Работает на компьютере и телефоне, устанавливается как веб-приложение и может открываться офлайн после первого посещения.

## Возможности

- Добавление, переименование и удаление привычек; в календаре есть стартовый список из примера.
- Отметки по каждому дню с мгновенным пересчётом показателей.
- Графики прогресса по дням и неделям, месячное кольцо и сравнение темпа с прошедшими днями.
- Текущая серия, рекорд выбранного месяца и число полностью закрытых дней.
- Выбор месяца; отметки сохраняются отдельно для каждого дня.
- Экспорт и импорт резервной копии JSON.
- Локальное сохранение и синхронизация между устройствами через GitHub API.

## Публикация через GitHub Pages

1. Создайте репозиторий для приложения на GitHub. Для бесплатной публикации GitHub Pages обычно используйте публичный репозиторий с исходниками приложения.
2. Загрузите в корень репозитория все файлы из этой папки, включая скрытую папку `.github/workflows`.
3. В настройках репозитория откройте **Settings → Pages** и выберите **GitHub Actions** как источник публикации.
4. После отправки файлов в ветку `main` workflow опубликует сайт. Адрес появится в разделе **Settings → Pages** и в запуске GitHub Actions.
5. Откройте ссылку на телефоне и компьютере. На телефоне браузер предложит добавить приложение на главный экран.

Workflow использует GitHub Actions и публикует статические файлы из корня репозитория. См. [официальную инструкцию GitHub Pages с пользовательским workflow](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages).

## Подключение синхронизации

GitHub Pages сам по себе хранит данные отдельно в каждом браузере. Для общей копии на телефоне и компьютере приложение записывает файл `ritm-habits.json` в **отдельный приватный репозиторий** GitHub.

1. Создайте новый GitHub-репозиторий для данных и выберите видимость **Private**. Например, `ritm-habits-data`.
2. Создайте fine-grained personal access token. Ограничьте его этим единственным репозиторием и выдайте разрешение **Contents: Read and write**.
3. В приложении откройте **Синхронизация**, введите токен и имя репозитория в формате `имя-пользователя/ritm-habits-data`, затем нажмите **Подключить и загрузить**.
4. При первом подключении приложение предложит записать текущие данные в репозиторий. На втором устройстве повторите подключение к тому же репозиторию. Если файл уже существует, приложение предложит загрузить его.

Токен можно оставить только до закрытия вкладки или отметить «Запомнить токен на этом устройстве». В любом случае токен хранится в хранилище браузера и отправляется напрямую в GitHub API; он не включён в исходники приложения. При создании токена ограничьте его доступ только репозиторием с данными.

## Хранение данных

Без синхронизации привычки хранятся только в текущем браузере. Удаление привычки удаляет её отметки за все месяцы. Экспортируйте JSON перед крупными изменениями, если хотите сохранить отдельную резервную копию.

Приложение не имеет собственной учётной записи или сервера. Ссылка на GitHub Pages доступна всем, кто её знает; личные отметки приложение не публикует на странице. Для синхронизации используется только приватный репозиторий, доступ к которому ограничен GitHub-токеном.
